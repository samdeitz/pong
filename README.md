# 🏓 Pong (Java HSA2 Game)

A Java HSA2 implementation of the classic arcade game "Pong".
Play with you and a friend and see who wins 👀
---

## ⌨ Controls & Rules
1. Use **W/S** for the left side and **↑/↓**
2. The goal is to get the ball past the other person's paddle.
3. The game will start each round after approximately 3 seconds.
4. First to 3 wins!

## 🎮 Play the Game

### Windows Only
1. Download the latest release: [PongGame.zip](https://github.com/samdeitz/pong/releases/download/v1.0/PongGame.zip)
2. Extract (unzip) the folder.
3. Open the folder and double-click **PongGame.exe** to start playing.
